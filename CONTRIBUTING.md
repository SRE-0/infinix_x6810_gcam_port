# Contribuir

Usa `python scripts/validate.py` y el APK original fijado por SHA-256 para build.
Mantén la selección de release independiente de los ensayos de DEX/smali. Las
mediciones deben indicar versión, condiciones, instrumento y limitaciones.
No publiques datos de usuario, trazas privadas ni APK reconstruidos automáticamente.
Los cambios RAW/OIS/flash pertenecen a
[infinix_x6810_raw](https://github.com/SRE-0/infinix_x6810_raw).
